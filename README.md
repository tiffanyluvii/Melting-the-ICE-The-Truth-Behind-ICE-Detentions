# Melting the ICE: The Truth Behind ICE Detentions

## Overview

Our visualization tells the story of ICE detentions in the United States between 2022 and 2026. We examine how detention patterns have changed between administrations with the use of various visualization techniques in a scrollable format. The goal of the visualization is to challenge assumptions of ICE and those detained by ICE to highlight the bleak reality of the detention system.

---

## Running the Visualization

To run our visualization, open this link:

https://tiffanyluvii.github.io/Melting-the-ICE-The-Truth-Behind-ICE-Detentions/

When opening the website, let it load for 1 minute before scrolling to allow the dataset to load in.

---

## Project Structure

Our project is structured into 8 sections, each having its own `section#.js` file in the `js/` directory. All of the sections are run independently on the `scripts.js` file.

### Directory Structure

```text
js/        → visualization sections and logic
css/       → styling
data/      → datasets
images/    → images and assets
audio/     → audio files
```

## Development Process

Our development process first involved manually brainstorming what type of visualization and specifics on how each section would look, then prompting AI to create an initial section. From this point, many iterations were needed with AI to make major adjustments, while minor adjustments like formatting, colors, and spacing were done manually.
